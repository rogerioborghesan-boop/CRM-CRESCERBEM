# CRM Crescer Bem

CRM da Crescer Bem: crédito rural (Pronaf, Pronamp e demais linhas), Proagro, laudos, vistorias e consórcios.

- `index.html`: o aplicativo (abre no navegador; os dados ficam no Supabase do projeto CRM-CRESCERBEM, protegidos por login).
- `modelos/`: modelos de contratos, declarações, autorizações e orçamentos em Word, com campos preenchidos automaticamente pelo CRM.
